# Capture

A modern, high-performance portfolio and agency website showcasing interactive web experiences, creative design, and 3D web graphics.

---

## ⚡ Tech Stack

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS
- **Animations & 3D:** Three.js, GSAP, Framer Motion, `@lucasmarkes/hairline`
- **Icons:** Lucide React

---

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/vishalvinzuda-dev/capture.git
   cd capture
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to the local server URL (typically `http://localhost:5173`).

---

## 🛠️ Build

To generate the production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
