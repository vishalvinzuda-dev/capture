# Agent Navigation & Fast Task Routing Rule

Whenever you are assigned any task in this repository:
1. **DO NOT perform recursive directory scans or wide searches across the whole project.**
2. **Refer directly to [CODEBASE_MAP.md](file:///f:/WebSites/04/CODEBASE_MAP.md)**:
   - For all copy, text, pricing, testimonials, company info, and stats: edit `src/data/content.ts`.
   - For the Meely 3D page, frame tour, and parallax: go to `src/meely/MeelyPage.tsx` and `public/meely-frames/`.
   - For main landing page sections: go directly to the corresponding component in `src/components/`.
   - For route handling or page sequence: go to `src/App.tsx`.
   - For design tokens, theme styles, or global CSS: go to `src/index.css`.
3. Check the **Fast Task Routing Matrix** in [CODEBASE_MAP.md](file:///f:/WebSites/04/CODEBASE_MAP.md) to locate the exact file in seconds.
